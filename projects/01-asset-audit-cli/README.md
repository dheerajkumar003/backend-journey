## Usage

```bash
npm run audit -- <assets-folder> [--max-kb=500] [--json report.json]
```

Examples:

```bash
npm run audit -- ./assets
npm run audit -- ./assets --max-kb=300
npm run audit -- ./assets --json report.json
```
